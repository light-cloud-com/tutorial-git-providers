# Deploy from Git to Light Cloud

A one-page static site used by the Light Cloud tutorials on deploying from GitHub, GitLab and Bitbucket. Change `Version 1` in `index.html`, push, and Light Cloud deploys the new version.

- [Deploy from GitHub](https://blog.light-cloud.com/tutorials/deploy-from-github)
- [Deploy from GitLab](https://blog.light-cloud.com/tutorials/deploy-from-gitlab)
